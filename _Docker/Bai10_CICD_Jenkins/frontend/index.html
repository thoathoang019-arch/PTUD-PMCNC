📚 Khái niệm chính

CI — Continuous Integration

  • Tự động: build + test mỗi khi có code mới
  • Test FAIL → DỪNG, không build image
  • "Build ra được" ≠ "code đúng"
  • Pipeline as Code (Jenkinsfile) — version control

CD — Continuous Deployment

  • Image đã test → push Registry → deploy
  • Máy CD KHÔNG build code — chỉ pull image
  • Webhook: CI "gõ cửa" CD sau khi push xong
  • Migration tự chạy khi app khởi động

Unit Test

  • Test 1 method/function — độc lập
  • Không cần database, network
  • Pattern: Arrange → Act → Assert
  • Framework: xUnit (.NET), Jest (JS), PyTest

Vì sao cần 2 máy?

  • Thực tế: CI server ≠ Production server
  • CI build → đóng gói image → push registry
  • CD pull image → deploy (không biết source code)
  • Jenkins localhost → không có webhook từ GitHub
